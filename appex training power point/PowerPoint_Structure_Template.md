## 🎨 Design Standards

### Color Scheme
- **Primary:** AppEx Blue (#1E40AF)
- **Secondary:** AppEx Purple (#764ba2)
- **Accent:** AppEx Gold (#FFD700)
- **Background:** Clean white/light gray
- **Text:** Dark gray (#1F2937)

### Typography
- **Headings:** Modern sans-serif (Arial, Helvetica)
- **Body:** Clean readable font (Calibri, Arial)
- **Sizes:** H1: 44pt, H2: 32pt, H3: 24pt, Body: 18pt
- **Weights:** Bold for headings, Regular for body

### Layout Standards
- **Margins:** Professional 1-inch margins
- **Alignment:** Left-aligned text, centered titles
- **Spacing:** Consistent line spacing (1.2-1.5)
- **Grid:** 12-column grid system
- **White Space:** Adequate breathing room

### Visual Elements
- **Logo:** High-resolution AppEx logo
- **Icons:** Consistent icon family
- **Images:** Professional screenshots/mockups
- **Diagrams:** Clean flowcharts and architecture
- **Charts:** Consistent color scheme

## 📋 Content Guidelines

### Writing Style
- **Tone:** Professional, educational, encouraging
- **Language:** Clear, concise, action-oriented
- **Terminology:** Consistent AppEx terminology
- **Examples:** Real-world scenarios
- **Instructions:** Step-by-step format

### Slide Content Rules
- **Maximum 6 bullet points** per slide
- **One main concept** per slide
- **Visual support** for all concepts
- **Progressive disclosure** from simple to complex
- **Interactive elements** where appropriate

### Quality Assurance
- **Spell check** all content
- **Consistent terminology** throughout
- **Accurate screenshots** and examples
- **Up-to-date information** on features
- **Professional formatting** and layout
